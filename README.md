# Operation Automation – n8n Workflows

This repository stores **n8n workflows** for the Operation Automation project.  
It is jointly maintained by the **Taiwan RAID/DS team** and the **Vietnam Nexcel team**.

## Project Scope
- **Create Event**
- **Event Check**
- **Get Result**
- **Trader Assignment**
- Other automation tasks

## Team Responsibilities
- **Taiwan Team (RAID/DS)**: Develop workflows for major leagues/events and initial development.
- **Vietnam Team (Nexcel)**: Maintain workflows for other leagues/sports, extend integration, and contribute enhancements.


## Contribution Guide
1. Export workflow from n8n in **JSON format**.
2. Place the JSON file in the corresponding folder.
3. Update `README.md` in that folder if necessary.
4. Open a Merge Request for review.
